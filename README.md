# Calendário bíblico e hebraico

Estudo em português sobre o calendário bíblico e hebraico, seus meses, festas, palavras hebraicas e relações com as tribos de Israel.

## Acessar o estudo

**[Abrir o estudo interativo](https://sharbocasagrande-ai.github.io/calendario-biblico/)**

Abra o endereço no Safari, Chrome ou outro navegador atual, no celular ou no computador. Toque nas palavras hebraicas para ver o significado e nos botões de áudio para ouvir.

- Pronúncia de palavras e expressões, com áudio sintetizado em hebraico.
- Velocidades normal, 0,75× e 0,5×; repetição e pausas para acompanhar.
- Modo de prática, favoritos e revisão por capítulo.
- Exibição opcional dos sinais vocálicos (niqqud).
- [Versão em PDF](estudo_calendario_biblico_hebraico_2026.pdf).

Os favoritos e as preferências ficam salvos no navegador de cada aparelho; não há sincronização entre dispositivos. Para abrir o endereço online, use uma conexão à internet. Os áudios estão incorporados ao HTML. Também é possível baixar o HTML e usá-lo em um navegador que execute arquivos locais.

## Conteúdo e fontes

O estudo apresenta referências bíblicas e fontes consultadas, distinguindo o texto bíblico, o calendário rabínico e associações interpretativas posteriores. A leitura em português é uma aproximação didática, e a pronúncia gravada é sintetizada.

## Atualização

O arquivo `index.html` reúne o conteúdo interativo, os estilos, a programação e os áudios. Para atualizar o site, substitua esse arquivo e, quando necessário, o PDF. A publicação usa GitHub Pages, a partir da raiz da branch `main`.
